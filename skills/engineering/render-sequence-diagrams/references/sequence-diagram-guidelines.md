# 时序图规范

## 范围与依据

每张图讲清一个入口到结束条件的场景；参与者按调用方向从左至右排列，使用稳定的英文 ID 与可读别名。用户、服务、队列、数据库分别按实际职责命名，避免把一个类的每个方法画成独立参与者。复杂调用链以总览加子流程表达，正文交代衔接点及省略的内部调用。

真实系统依据当前版本的源码、协议或追踪记录；分清实际调用和推测。源码只显示返回 Publisher、Future 等对象时，不把其创建顺序当作订阅或异步执行顺序。并发需有并发机制依据，不凭排版推断。

## 消息与控制结构

- 以 `sequenceDiagram` 开始，默认 `autonumber`；参与者用 `actor` 或 `participant X as 标签` 显式声明。
- 同步调用用 `A->>B: method(关键参数)`，返回用 `B-->>A: 结果`；异步投递用 `A-)B: 事件`，具体完成需另画回调、消费或确认消息。箭头符号是本技能的表达约定，必须与实际语义一致。
- 激活条只表示一段处理区间，`activate` 与 `deactivate` 成对；分支中区间容易失衡时省略激活条。图中的条件要写实际判断，避免只有“成功/失败”却没有判断依据。
- `alt/else/end` 表示互斥路径；`opt/end` 表示可选路径；`loop/end` 写明循环条件或次数；`par/and/end` 表示真实并行；`critical/option/end` 仅用于有互斥约束的场景。
- 错误路径说明触发条件、返回或异常，以及调用方如何处理；根据任务范围涵盖超时、取消、重试，未覆盖的情况写在正文。重试不等于幂等，未证明时不画出幂等保证。
- `Note over A,B: 说明` 用于边界、事务和假设；长标签用 `<br/>` 换行。业务文本含 Mermaid 保留字（如独立的 `end`）时使用括号或引号并实际渲染验证。

## 参与者名称与尺寸

源码类型名保留完整拼写。参与者声明用 `participant Model as nowrap: ChatModelCallAdvisor`（actor 同理），由 Mermaid 按文字自然宽度扩展，避免自动断词或插入连字符；组合角色可用显式 `<br/>` 在职责分隔处换行，类型名本身保持完整。模板使用 classic 外观与 65 SVG 单位的标准参与者框高，缩放时按比例显示。宽图通过画布滚动与缩放查看，不能靠截断类型名缩窄。消息仍可自动换行。

## 文件布局

HTML 统一放在交付目录顶层。将 Markdown、符号映射（如适用）归入 `sequence-diagrams/`，审计资料按需放进模块内的 `audits/`。运行资源由生成器写入 `sequence-diagrams/<topic>.assets/`。源 Markdown 位于该模块目录时，默认在其上一层生成同名 HTML；`--output` 可指定 HTML 路径。迁移时保持模块目录与 HTML 的相对位置。

## 展示与交付

时序图与图例共用下列功能颜色。参与者图形、箭头型式以及片段标记共同表达语义，颜色辅助识别。

| 元素 | 形状与颜色 |
| --- | --- |
| 参与者与生命线 | 浅蓝框或蓝色人物，蓝色生命线 |
| 调用、返回、异步投递 | 深灰蓝箭头，分别用实线填实箭头、虚线填实箭头、实线开放箭头 |
| 条件与可选片段 | `alt` / `opt` 的角标和边框用浅黄与金褐色，条件文字置于框内 |
| 循环、并行 | `loop` 用淡紫，`par` 用青绿，保留明确的片段标记 |
| 注释、激活区间 | 注释用浅黄矩形，处理区间用蓝色窄条 |
| 已确认结果 | 可用 `rect rgb(220, 252, 231)` 标出成功结果，`rect rgb(254, 226, 226)` 标出失败或拒绝，在消息文字中写出对应结果 |

窄屏使用横向滚动。超长图优先按业务阶段拆分，保留可读字号。

Markdown 中保留依据和解释；HTML 采用紧凑页头、单行场景导航、紧凑可折叠工具栏及填满窗口剩余高度的画布。场景使用横向平铺标签，超出导航宽度时裁切隐藏，不换行、不使用下拉框；左右按钮与键盘方向键循环切换，Home/End 到首尾，选中标签自动移入可见范围。支持适应整图、100% 与手动缩放、Shift + 滚轮缩放、浏览器全屏/屏幕全屏及 SVG 导出。核对图例、画布和导出 SVG 的符号及功能颜色一致，且保留文本、箭头和分组；多图切换不应跳动页面滚动位置。生成器不做完整 Mermaid 语法校验，浏览器报错时修正源 Markdown 后重新生成。

页头右上方的折叠图例用符号样例说明参与者、生命线、箭头、分组、激活条、注释和消息编号。打开时覆盖画布上方，关闭后回到原图位置。窄屏检查图例可展开、滚动和关闭。

语法依据：[Mermaid 官方时序图文档](https://mermaid.js.org/syntax/sequenceDiagram.html)。运行时以本技能内置版本为准，新语法先验证兼容性。

多图默认使用相同缩放比例，切换场景及展示模式保留当前比例，使参与者框高与字号保持一致；适应整图由用户主动触发。需要指定初始比例时，在输入 Markdown 加入 `<!-- sequence-viewer: {"initialZoom": 0.71} -->`；未指定时为 100%，支持 10%–300%。该设置随源码快照保留，重新生成可复现。

参与者在顶部与底部镜像展示（`sequence.mirrorActors: true`），两端保持相同类型图形、完整名称、顺序、框高与字号，便于沿生命线追踪长图。

## 源码导航

映射 JSON 包含 `symbols`（与类图相同的 className / methods / methodName / parameterTypes）、`diagrams`（按输入顺序）。每图记录 Mermaid 原文的 SHA-256 `sourceHash`、以参与者 ID 为键的 `participants`，以及按消息箭头出现顺序排列的 `messages`。参与者填写显示标签；没有别名时用参与者 ID，包括由消息隐式声明的参与者。消息含 from/to/label。每项含 links 或具体 reason。links 项为 `{text, symbol, method?}`，symbol 指向 symbols 键，method 指向其 methods 键；text 为显示片段。返回、事件、外部服务和概念步骤用 reason 排除，不能自动从同名方法猜测声明。继承方法和重载需要核对源码或同版本二进制。

模板为上下参与者类名与消息方法片段建立独立 SVG 链接，使用 data-source-symbol / data-source-method，由新版 IDEA bridge 从清洗过的 source-map 解析目标，忽略任意页面提供的目标 JSON。链式调用分别链接每个方法，片段必须保持连续可读；若 Mermaid 换行拆开方法名，显式 nowrap 该消息并重新核对入口数。

`--source-map` 提供映射即启用严格检查；也可在 sequence-viewer 注释加入 `"sourceMap":"symbols.json"`，相对输入 Markdown 解析，使普通重生成保留导航。严格模式核对每图哈希、全部参与者及消息标签覆盖、精确符号引用。模板与生成器变更要检查重复生成字节一致、旧映射拒绝生成、HTML/Markdown/映射快照一致、浏览器入口数与预期一致、导出 SVG 元数据。使用 IDEA 菜单建立会话；普通浏览器只提示，不声称打开成功。插件需支持通用符号键链接；既有仅识别 g.node 的版本需更新。

## IDEA 真实验收与失败分类

真实打开检查需保存每项最终结果与去重目标。`not_found` 先核对 IDE 是否导入包含该类型的依赖；Maven 缓存存在 JAR 只证明文件已下载，不能证明 IDEA 已索引。需要用户授权导入的导航依赖时，使用项目已有导航模块，不替换为能打开但不相干的类。

同一 FQN 在不同模块出现时，`ambiguous` 不是成功。保留候选文件并根据图的源码范围选择对应模块，例如第 7 章流程不能选第 14 章同名控制器。交互选定后记录单独的 manual-opened 证据，不改写原自动审计中的 ambiguous，不把自动检查汇总伪装成 100%。迁移技能或更新模板后重新执行生成检查；正式源码目录为维护来源，安装缓存应与之同步。

导航标签使用原生横向滚动，触摸与触控板沿用浏览器的连续运动和惯性；滚轮可连续浏览标签，鼠标拖动随手移动并在松手后按帧衰减滑行，边界停止。滑动只浏览标签，点击标签才选择场景；左右按钮与键盘仍切图，选中标签平滑移入可见范围。不要将滑动累计成阈值后突然切图。拖动抑制误点击；新手势打断惯性，取消手势停止，减少动态效果时停用额外惯性和平滑定位。该逻辑由 sequence-navigation.js 随产物打包，默认及全屏导航共用。
